# Pre-publish checklist (per page / post)

- [ ] Title tag under 60 characters, contains the page's primary keyword
- [ ] Meta description under 155 characters, primary keyword + concrete value proposition
- [ ] Exactly one H1, contains the primary keyword
- [ ] Primary keyword appears naturally in the first 100 words
- [ ] Page opens with a 40–60 word direct answer a machine could quote
- [ ] H2/H3s are question-shaped where a buyer would actually ask one
- [ ] FAQ section: 3–5 real questions, self-contained 2–4 sentence answers
- [ ] FAQPage JSON-LD matches the visible FAQ text exactly
- [ ] Business name + location + offer in the first 100 words
- [ ] Every number, award, review, and credential traces back to client/profile.md
- [ ] Byline with real name and credential (blog posts)
- [ ] At least one internal link to a service or about page (blog posts)
- [ ] Passed the full final self-check in writing-rules.md
